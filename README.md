## Requirements

- Apple-silicon Mac running macOS 14 or newer.
- A working Apple Music or Roon setup.
- Internet access for downloads and online services.

Core includes its runtime; installation does not require Python, Homebrew,
Xcode, or a source checkout. Start with music controls and add optional panels
when you reach them in the guide.

The optional native iPhone/iPad app currently requires iOS/iPadOS 26 or newer,
device registration by the app publisher, and Developer Mode. Obtain its
installation link from the publisher. Phone access to your own Core uses your
own Tailscale network.
